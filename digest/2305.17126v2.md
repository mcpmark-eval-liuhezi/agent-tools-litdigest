# Large Language Models as Tool Makers

- **arXiv ID:** 2305.17126v2
- **Title:** Large Language Models as Tool Makers
- **Authors:** Tianle Cai, Xuezhi Wang, Tengyu Ma, Xinyun Chen, Denny Zhou
- **URL:** https://arxiv.org/abs/2305.17126

## Summary

The core claim is that LLMs need not be limited to consuming pre-supplied tools but can manufacture reusable tools of their own. LATM is a two-stage closed loop: a powerful "tool maker" writes a generic Python function from a handful of demonstrations, self-verifies it by generating and running unit tests, and wraps it with call-format examples; a cheap "tool user" model then applies the wrapped tool to fresh task instances via in-context learning. Because tool-making happens once per task family and the resulting tools can be cached and dispatched, the framework doubles as a "functional cache" over serving requests, and pairing GPT-4 as maker with GPT-3.5 as user matches GPT-4-only performance on Big-Bench tasks at a fraction of the inference cost.
