# AutoTool: Efficient Tool Selection for Large Language Model Agents

- **arXiv ID:** 2511.14650v1
- **Title:** AutoTool: Efficient Tool Selection for Large Language Model Agents
- **Authors:** Jingyi Jia, Qinbin Li
- **URL:** https://arxiv.org/abs/2511.14650

## Summary

The paper's claim is that in agent frameworks such as ReAct the dominant bottleneck is the repeated LLM inference needed just to decide which tool to call next, and that this cost can be sidestepped by exploiting "tool usage inertia" — the empirically strong predictability of tool-call sequences. AutoTool builds a Tool Inertia Graph from historical trajectories, with tool nodes carrying parameter sub-nodes and weighted directed edges capturing both tool-to-tool transitions and parameter-level data flow; an inertia-sensing step scores candidate next tools by a blend of frequency and contextual relevance, and parameter arguments are filled by backtracking data flow on the graph. An inertial call is executed only if both stages succeed, otherwise control reverts to the standard LLM path, yielding up to roughly 30% lower inference cost while keeping task completion competitive.
